FAQ

Frequently asked questions.

What is Browseterm, in one sentence?

Software you install on your own Mac, Windows PC, or Linux machine that turns it into a Linux workspace you can open and use from any web browser.

Does my code/data leave my machine?

No. Your workspaces run entirely on the machine you install Browseterm on. Browseterm Cloud only coordinates login, device tracking, and commands — it does not run your workloads or store a live copy of your files.

Do I need Docker Desktop?

No. On macOS and Windows, Browseterm manages its own dedicated, isolated virtual machine. On Linux, Browseterm runs natively without Docker at all.

Can I use more than one machine?

Yes. You can register multiple devices on your account. At any time, one device is your active device — the one new workspaces are created or resumed on. Workspaces you've saved on an inactive device stay saved and can be resumed once that device is active again.

What happens if my machine is off or asleep?

Your machine has to be on and connected for its workspaces to be reachable. Browseterm is honest about this: it will never claim a workspace is available when the machine hosting it isn't actually online.

Is my machine exposed to the internet?

No. Your machine only ever makes outbound connections to Browseterm Cloud — nothing can connect into your machine from the outside. See the Security page for details.
