Install Browseterm on Windows

Browseterm on Windows runs your workspaces inside a dedicated, managed Ubuntu virtual machine. It does not require Docker Desktop or your own WSL distribution.

macOS Windows Linux

Requirements

  • Windows 10 or later, 64-bit
  • Hardware virtualization enabled in your system firmware/BIOS
  • Administrator access, for the one-time virtualization setup
  • An active internet connection for setup and to sign in to Browseterm Cloud

Download

Download Browseterm for Windows (64-bit) — release coming soon

Setup

  1. Run the downloaded Browseterm Desktop installer as Administrator.
  2. If hardware virtualization isn't already enabled, Browseterm will tell you and explain the one-time firmware setting to turn on — a restart is required after enabling it.
  3. Browseterm guides you through the official Multipass installation if it isn't already present.
  4. Choose how much CPU, memory, and storage to give Browseterm from your PC's resources — you can change this later.
  5. Browseterm creates a dedicated Ubuntu virtual machine and starts your local Browseterm environment inside it.
  6. Sign in with your Browseterm Cloud account to link this PC as a device.
  7. Open app.browseterm.puhtaeto.com in your browser and create your first workspace.
Starts automatically. Browseterm registers itself to start automatically when you sign in to Windows.

Uninstalling

Use "Add or remove programs" to uninstall Browseterm. You'll be asked whether to keep or remove your workspace data.
