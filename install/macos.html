Install Browseterm on macOS

Browseterm on macOS runs your workspaces inside a dedicated, managed Ubuntu virtual machine on your Mac. No Docker Desktop required.

macOS Windows Linux

Requirements

  • macOS on Apple Silicon (arm64) or Intel (amd64)
  • Hardware virtualization support (built in on all supported Macs)
  • An active internet connection for setup and to sign in to Browseterm Cloud

Download

Download Browseterm for macOS (arm64) — release coming soon

Download Browseterm for macOS (Intel) — release coming soon

Setup

  1. Open the downloaded Browseterm Desktop installer and follow the on-screen macOS installation/permission prompts.
  2. On first launch, Browseterm checks for the Multipass virtualization tool. If it isn't already installed, Browseterm guides you through the official, signed Multipass installation.
  3. Choose how much CPU, memory, and storage to give Browseterm from your Mac's resources — you can change this later.
  4. Browseterm creates a dedicated Ubuntu virtual machine and starts your local Browseterm environment inside it.
  5. Sign in with your Browseterm Cloud account to link this Mac as a device.
  6. Open app.browseterm.puhtaeto.com in your browser and create your first workspace.
Starts automatically. Browseterm registers a background login item so your environment comes back up automatically after a restart.

Uninstalling

Browseterm's uninstaller removes the virtual machine and background service. Your workspace data can optionally be preserved or removed — you'll be asked which you want.
